# 御枢 · SecNexus
> 安全运营探针平台，面向攻防演习、资产监测、威胁采集场景

## 📌 项目简介
御枢SecNexus 是自研安全探针组件，用于内网资产采集、告警上报、状态探测，适配企业安全运营、红蓝对抗、常态化护网场景。

## 📦 版本
当前稳定版：**v1.2.1**

## 📁 目录结构
```

SecNexus_v1.2.1/
├── SecNexus.exe                # 探针主程序
├── SecNexus.lic                 # 授权许可文件
├── data/                       # 持久化配置、缓存目录
├── Example/                    # 示例配置模板
├── 御枢・SecNexus 用户使用操作手册.md       # 用户操作手册
└── 御枢・SecNexus 用户使用操作手册.md.zip  # 手册压缩包

```

## 🚀 快速部署
1. 获取授权文件 `SecNexus.lic`，与 `SecNexus.exe` 放在同一目录
2. 参照【御枢·SecNexus用户使用操作手册.md】完成参数配置
3. 启动探针，验证连通性与上报状态
4. 日志、运行数据自动写入 `data` 目录
